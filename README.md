# Java Blackjack 
This program is a command line blackjack game that uses object-oriented programming principles to implement numerous features.

## Features
- Blackjack game with player and dealer supported logic.
- Payout and Balance tracking logic with fluctuating currency.
- Split and Double Down logic.
- Ace logic that supports valuation as either 1 or 11 when necessary.
- Ability to replay as many times as one would like.
- User input validation. 

## Used Technology
- Java
- Object-Oriented Programming
- Java Collections Framework 

## How to Run
- Download or clone repository.
- Open the project in a Java IDE.
-  Run Main.java to play.

## Structure 
- Main.java - Entry point
- Card.java - Card Class to create objects
- Deck.java - Deck Class to manage deck of cards.
- Payout.java - Betting and payout management.
- Game.java - Major Blackjack logic class.
